# Resource List

Every website mentioned in the course, sorted by what it's for. All of them are
free to use (some have optional paid extras).

> Websites change. If a link breaks, search its name, or paste the link into the
> [Wayback Machine](https://web.archive.org).

---

## Search engines

| Site | Best for |
|---|---|
| [Google](https://www.google.com) | General searching with operators (Lesson 01) |
| [Google Scholar](https://scholar.google.com) | Research papers |
| [Bing](https://www.bing.com) | A second opinion with a different index |
| [DuckDuckGo](https://duckduckgo.com) | Private searching, "bangs" shortcuts |
| [DuckDuckGo without AI](https://noai.duckduckgo.com) | DuckDuckGo with all AI answers turned off |
| [Brave Search](https://search.brave.com) | Independent index, forum discussions |
| [Startpage](https://www.startpage.com) | Google results without tracking |
| [Mojeek](https://www.mojeek.com) | Small independent index |
| [Marginalia Search](https://marginalia-search.com) | Small, personal, non-commercial websites |
| [Google Dataset Search](https://datasetsearch.research.google.com) | Datasets |
| [Hacker News search](https://hn.algolia.com) | Tech discussions |
