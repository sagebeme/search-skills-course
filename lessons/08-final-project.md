# Lesson 08: Final Project — Build Your Own Free Learning Plan

**Goal:** use every skill from this course to build a complete, free, trusted
learning plan for one real topic, one you (or someone you're helping) actually
want to learn.

**Time:** 2–3 hours, can be spread across several days.

---

## What you'll make

A single document (a notebook page, a text file, or a Markdown file) called
**"My free plan to learn <topic>"**. It has six sections.

### 1. The question

- What do you want to learn, and why?
- What's your current level (complete beginner, some basics, etc.)?
- How much time per week can you give it?

### 2. Your search words (Lessons 00–01)

- Your first, everyday wording of the topic.
- The **expert words** you discovered while searching.
- Your **three best search strings**, including operators, and what each found.

### 3. The core resources (Lessons 02, 03, 07)

Pick **one main course** and support it:

| Role | Resource | Link | Why I chose it |
|---|---|---|---|
| Main course | | | |
| Textbook / reading | | | |
| Official docs or official guide | | | |
| Practice / exercises | | | |
| Data or real-world examples (if useful) | | | |

### 4. Communities (Lessons 04–05)

| Platform | Community | How I found it | Trust check (green / red flags) |
|---|---|---|---|
| Reddit | | | |
| Telegram | | | |
| Other (Stack Exchange, forum, Discord, local group) | | | |

Include the **three free resources the community wiki or FAQ recommends**, and
note whether they agree with your own choices.

### 5. Safety and trust check (Lessons 00, 06)

For each resource above, confirm:

- [ ] I opened it by going to the **real, official website**, not through a
      random link.
- [ ] I ran **SIFT** on it: I know who made it and what others say about them.
- [ ] Nothing asked me to pay to "unlock", install an unknown file, or share
      codes or passwords.
- [ ] It's **legal**: free from the creator, an open licence, the public domain,
      or a library loan.

### 6. The plan

Turn it into a simple weekly schedule. For example:

| Week | What I'll do | Resource | How I'll know I've got it |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

"How I'll know I've got it" should be something you can **do**: solve 10
practice problems, explain the idea to a friend, build a small project, pass a
free quiz.

---

## Finish strong

1. **Compare paid vs. free.** Find the most popular paid course on your topic.
   Write two or three sentences: what does it offer that your free plan doesn't?
   Is that worth the money **to you**? (Sometimes the honest answer is yes:
   structure, feedback, or a recognised certificate can be worth paying for. The
   point is to decide with full information.)
2. **Teach someone.** Share your plan with one person who wants to learn
   something. Walk them through **one** search technique from this course. This
   is how the skill spreads.
3. **Save your sources.** Put your most important links into the Wayback
   Machine with **"Save Page Now"** (Lesson 02) so they don't disappear.

---

## Self-check: did I learn the course?

You can say "yes" to all of these:

- [ ] I can turn a vague question into strong search words.
- [ ] I can use `site:`, `filetype:`, `intitle:`, `inurl:`, quotes, `-`, `OR`
      and `before:`/`after:` without looking them up.
- [ ] I can find a free legal copy of a research paper, or know how to ask for one.
- [ ] I know at least two search engines besides Google and when to use them.
- [ ] I can find, preview and judge a Telegram channel before joining.
- [ ] I can find a subreddit's wiki and search Reddit both directly and through
      Google.
- [ ] I can spot a fake link, a dangerous file and a "free course" scam.
- [ ] I know where to find free courses, open textbooks, library e-books and
      official docs.

Congratulations. You don't need a gatekeeper to learn. You know how to find the
door yourself.
